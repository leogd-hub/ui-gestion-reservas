# Mocks

Servicios mock asíncronos con:

- Latencia simulada (`MockAsyncRunner`)
- Fail rate configurable
- Seeds iniciales para usuarios, pricing, direcciones y métodos de pago

Servicios disponibles:

- `MockAuthService`
- `MockPricingService`
- `MockMapService`
- `MockPaymentService`
- `MockReservationService`
